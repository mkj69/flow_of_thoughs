# Start Here

Three reading paths depending on what you want to understand.

## Path 1 — Recurrent depth and test-time compute

1. **Universal Transformers** (2018) — the recurrence-over-depth ancestor.
2. **Scaling up Test-Time Compute with Latent Reasoning** (2025) — modern recurrent-depth scaling.
3. **LoopFormer** (2026) — variable compute budgets.
4. **Parcae** (2026) — stability + scaling laws.
5. **Loop, Think, & Generalize** (2026) — depth extrapolation and overthinking.

Question to keep in mind: **why should another loop help rather than merely repeat the same computation?**

## Path 2 — Latent reasoning

1. **Coconut** (2024) — continuous thought as hidden state feedback.
2. **PonderLM-2** (2025) — extra latent steps per token.
3. **PonderLM-3** (2026) — adaptive allocation of those steps.
4. **Latent Recurrent Transformer** (2026) — cross-token recurrent latent memory.

Question to keep in mind: **what information is present in a latent thought that is not already available to the next-token predictor?**

## Path 3 — Flow and dynamical-systems view

1. **Scalable Adaptive Computation for Iterative Generation (RIN)** (2023) — recurrent self-conditioning in iterative generation.
2. **Flow Reasoning Models** (2026) — flow + recurrent refinement.
3. **Solve the Loop: Attractor Models** (2026) — fixed points / equilibrium refinement.
4. **Thinking with Looped Flows** (2026) — local denoising objectives + recurrent test-time compute.
5. **Parcae** (2026) — explicit dynamical-systems stability analysis for loops.

Question to keep in mind: **can reasoning progress be characterized by convergence in a meaningful state space?**
